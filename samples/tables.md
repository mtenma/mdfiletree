# 表の再現テスト

## 2. 列の寄せ（左・中央・右）

| 左寄せ | 中央寄せ | 右寄せ | 既定 |
| :----- | :------: | -----: | ---- |
| left | center | right | default |
| あ | い | う | え |
| 1 | 22 | 333 | 4444 |

## 3. 列の結合（colspan）

セル内容の後ろにパイプを重ねると、右の列と結合します。

|              |          グループ           ||
| 第1見出し    | 第2見出し     | 第3見出し   |
| ------------ | :-----------: | ----------: |
| 内容         |          *長いセル*         ||
| 内容         |   **セル**    |        セル |

## 4. 行の結合（rowspan）

`^^` を書いた列は、ひとつ上のセルと結合します。

Stage | Direct Products | ATP Yields
----: | --------------: | ---------:
Glycolysis | 2 ATP ||
^^ | 2 NADH | 3--5 ATP |
Pyruvate oxidation | 2 NADH | 5 ATP |
Citric acid cycle | 2 ATP ||
^^ | 6 NADH | 15 ATP |
^^ | 2 FADH2 | 3 ATP |
**30--32** ATP |||
[ヘキソースあたりの ATP 収量]

## 9. セルの中に色々入れる

| 種類 | 内容 |
| ---- | ---- |
| 強調 | **太字** と *斜体* と ~~打ち消し~~ と ==ハイライト== |
| コード | `const x = 1` |
| リンク | [外部リンク](https://www.markdownguide.org/) / [別の文書](./kitchen-sink.md) |
| 数式 | $E = mc^2$ |

| 改行 | 1行目<br>2行目 |
